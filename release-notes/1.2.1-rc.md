## zh-CN

- Windows 桌面版：本地运行的安装版应用，支持系统托盘与全局快捷键。
- AI 服务设置重构：账号服务与托管服务分页展示，未连接服务紧凑排列。
- AI 助手：统一输入工具栏（模型与上下文控制）、Codex 原生会话、本地文件接入与语音听写。
- 职位管理：自定义排序与职位置顶、可恢复的深度匹配任务。
- 面试准备：准备目标管理、题库分类筛选、面试反馈生成修复。
- 扩展：Notion 连接与页面编辑、自动填写插件 ATS 匹配修复。
- 界面：石墨深色主题、昵称字母头像、任务与题库筛选布局优化。
- 设置：迁移到新电脑指南、「关于」页版本与构建信息随安装包同步。

## en

- Windows desktop app: a packaged local install with system tray and global shortcuts.
- Reworked AI service settings: account and managed tabs, compact list for unconnected services.
- AI assistant: unified composer toolbar with model and context controls, persistent Codex native sessions, local files and voice dictation.
- Jobs: custom ordering with pinned jobs, resumable deep-match tasks.
- Interview prep: prep goals, question-bank category filters, duplicate-feedback fix.
- Extensions: Notion connection and page editing, auto-apply ATS matching fixes.
- UI: graphite dark theme, nickname avatars, improved task and question filters.
- Settings: move-to-new-computer guide; the About page now tracks the packaged version and build.
