## zh-CN

- AI 助手修复：收起或关闭聊天面板不再中断进行中的回答（后台继续生成，重开可见结果）；显式「停止」仍是唯一取消途径。
- AI 助手修复：发送或重新生成遇到会话写入冲突时自动重放一次，「重新生成」恢复首次点击即生效。
- AI 助手新增：当前角色先作答，再可给出「转交」卡片一键切换到更合适的角色；转交携带原文、粘贴内容、文件附件与手动上下文作为草稿，需本人确认后发送。
- AI 助手：Codex 原生入口并入模型选择，原生会话失败原因可见，支持 Codex CLI 受管更新。
- 界面：整窗缩放与可重绑定缩放快捷键。
- 扩展：Notion 页面内直接编辑正文、删除页面一次确认。
- 面试准备：桌面端「继续准备」改指向扩展工具中的 Web 练习入口（内置练习界面已在桌面端退役）。
- 设置：「关于」页随版本展示更新说明；AI 指派设置不再因服务探测空等；Antigravity 账号登录（待验证）。

## en

- AI assistant fixes: collapsing or closing the chat panel no longer interrupts a turn — generation continues in the background and the result is visible on reopen; explicit Stop remains the only cancel path.
- AI assistant fixes: send/regenerate now auto-retries once on conversation write conflicts, so Regenerate works on the first click.
- AI assistant: the answering role can offer a one-click handoff card to a better-fit role; the transfer carries the original text, paste content, file attachments and manual context as a draft for review — nothing auto-sends.
- AI assistant: Codex native sessions are integrated into the model picker, native session failures surface their reason, and the managed Codex CLI can be updated in-app.
- UI: whole-window zoom with rebindable zoom shortcuts.
- Extensions: edit Notion page content in place and delete pages with a single confirmation.
- Interview prep: in the desktop app, "Continue preparing" now points to the Web practice entry under Extension tools (the built-in practice surface is retired in desktop).
- Settings: the About page shows bundled release notes; AI assignment settings no longer wait on runtime probes; Antigravity account sign-in (pending verification).
