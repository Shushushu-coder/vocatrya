## zh-CN

- 统一多角色对话：三个 AI 角色合并为一个聊天入口与一个用户会话，输入区不再手动切换角色；连续追问自动跟随当前角色，只有明确的新目标才会切换，意图不明时由执行助手（Pilot）接待，待办清单始终跟随当前会话。
- 伙伴形象与接力回复：三位原创伙伴头像与中文主名（执行助手 Pilot / 职业顾问 Insight / 复盘教练 Reflect）随每条回复署名；一次包含多个目标的请求可由两个角色按顺序接力，显示为连续两条独立回复，可中途停止、仅重试失败的一步，或从回复菜单换一个角色再答一次。
- 模型配置分组：设置页改为「基础配置（默认模型 + 可选智能调度）/ AI 角色 / 专项功能」三组；「智能调度」推荐选择便宜快速的轻量模型用于幕后分流，留空时回退默认模型；显式配置失效时明确报错，不静默切换其他账号。旧版按角色分槽的历史会话保留为独立条目并可继续续聊。
- Codex 联网搜索与权限：Codex 原生会话可按需实时联网搜索，搜索卡片与来源随消息保存；原生权限提供推荐档位（默认推荐「帮我审批」，选择「完全访问」时提示风险自担）；支持 Codex CLI 0.165.0 及以上版本并保留运行时自检。
- Codex 本地业务工具：Codex 原生会话可经应用受控工具查询职位、简历与今日待办，并在授权范围内执行写入；需要批准的写入会生成审批卡片而不中断当前回复，批准或拒绝后形成闭环，退出重开后记录仍可查看。
- 托管 AI 上下文压缩：按所选模型窗口动态规划预算，支持微压缩、结构化摘要与手动压缩；长对话中的重要业务记录可重新挂回上下文，压缩过程可见进度。
- 长期记忆与偏好：对话中表达的偏好与目标可沉淀为跨会话长期记忆，设置页可查看、新增、编辑与删除，手写条目锁定后不被后台整理覆盖；求职偏好未填写的维度，岗位匹配与待办建议可参考对话沉淀偏好并标注来源，与已填偏好冲突时以已填为准。
- 今日待办：顶栏新增清单入口与完成计数，浮层提供圆形勾选、一句话事项与跳转箭头，清单按会话与日期独立。「今天做什么？」生成待办草稿卡，点「采用计划」后才保存；显式安排（添加、勾选、移到明天等）直接保存并可撤销。勾选不改变真实投递与面试记录，刷新与重启后清单保留。
- 飞书云文档：扩展工具新增飞书入口，使用自建应用的 App ID/Secret 连接；应用仅能访问被授权或分享的资源，可按名称浏览与过滤可访问的文档、文件夹与知识库（首版非全文搜索）、读取文档内容、创建文档、追加内容与改写指定段落，写入均经审批确认。不包含消息、日历、多维表格与文档删除。

## en

- Unified multi-role chat: the three AI roles merge into a single chat entry and one conversation — the manual role picker in the input area is gone. Follow-up questions stay with the current role, only clearly new goals switch, and vague first messages are answered by Pilot (the action assistant); the to-do list always follows the current conversation.
- Partner identities and relay replies: three original avatars sign each reply as Pilot (action assistant), Insight (career advisor) or Reflect (review coach). A request with multiple goals can be handled by two roles in sequence as consecutive separate replies; you can stop midway, retry only the failed step, or pick another role from the reply menu.
- Grouped model settings: the settings page is regrouped into General (default model + optional smart routing) / AI roles / Specialized features. Smart routing recommends a cheap, fast lightweight model for behind-the-scenes dispatch and falls back to the default model when empty; an invalid explicit configuration reports an honest error instead of silently switching accounts. Legacy per-role conversations are kept as separate entries and can be continued.
- Codex web search and permissions: native Codex sessions can search the web live on demand, with search cards and sources saved alongside the message. A recommended permission tier is provided ("Approve by rules" is recommended; choosing "Full access" shows an at-your-own-risk notice). Codex CLI 0.165.0 and later is supported with runtime self-checks.
- Codex local business tools: native Codex sessions can query jobs, resumes and today's plan through the app's controlled tools, and run writes within your authorization. Writes that need approval produce a non-blocking approval card instead of stalling the current turn; approving or rejecting closes the loop, and records remain readable after restarting the app.
- Managed AI context compaction: the budget adapts to the selected model's context window, with micro-compaction, a structured summary and a manual compact action; important business records can be re-anchored into context, with visible progress.
- Long-term memory and preferences: preferences and goals expressed in conversation can settle into cross-session long-term memory, manageable in Settings (view/add/edit/delete); manually written entries are locked and never overwritten by background curation. When a job-search preference dimension is unset, job-match analysis and to-do suggestions may draw on conversation-deposited preferences with a source label — explicitly set preferences always win on conflict.
- Today's plan: a new title-bar entry with a completion counter opens a light popover of circle checkboxes, one-line items and jump arrows; lists are scoped per conversation and per date. "What should I do today?" produces a draft card saved only when you choose "Adopt plan"; explicit instructions (add, check off, move to tomorrow) save directly with undo. Checking an item doesn't change real application or interview records, and lists persist across refresh and restart.
- Feishu cloud docs: a new Feishu entry under Extension tools connects with your self-built app's App ID/Secret. The app can only access resources it has been granted or shared — browse and filter accessible docs, folders and wiki spaces by name (no full-text search in this version), read document content, create docs, append content and rewrite specific blocks; all writes go through approval. Messaging, calendar, bitable and document deletion are not included.
